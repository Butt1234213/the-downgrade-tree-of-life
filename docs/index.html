Protein presets

Hi again, time for another 1.79e308 word info box!

This is the Protein preset menu, and at this point I'm gonna assume you know the Protein notation from making a few Microorganisms.

The Protein preset notation is similar, but instead of just using numbers, it uses ratios.

For example, if you have a preset of {2, 0, 8, 0, 0, 0, 0, 0}, it is describing a preset where you have 2 RuBisCo Proteins for every 8 Arganine Proteins.

Loading a preset will run the DNA Blueprint autobuyer and will automatically assign DNA Blueprints based upon the DNA Blueprint autobuyer's interval. By default, the autobuyer will try to make all possible DNA Blueprints when a preset is loaded.

The halt button exists to stop the autobuyer if it gets stuck for some reason.

Microorganism Info

If you've ever played AD or IMR you will know how these work (mostly)

This is a Microorganism.

You get a Microorganism by clicking one of the chosen Microorganisms and then Reinforcing. (I did originally intend for it to randomly give you one upon reinforcement for not clicking one but I was lazy)

It has three components: A level, a type, and a nature. (Top left number is its level, the image in the middle is its type, and the image in the bottom right is its nature.) In this case, this Microorganism would be a Level 3 Lively Amoeba.

Choosing a Microorganism's nature is easy enough, as you are given all 6 natures to pick from upon Reinforcement.

The Microorganism's type and level are a bit more complicated, though.

Both the type and the level depend on your current Protein setup, and we're gonna need some notation to show Protein setup layouts.

Protein Notation

This is what the notation will boil down to. Each Protein name will correspond to the number of said Protein you have. (Free Proteins do not count for this notation, only the ones you have actually assigned count.)

[# of RuBisCo Proteins, # of Extensin Proteins, # of Arganine Proteins, # of Glutamine Proteins, # of Glutamate Proteins, # of Asparagine Proteins, # of AGP Proteins, # of TRB Proteins]

Your current Protein setup is [0, 0, 0, 0, 0, 0, 0, 0].

Microorganism Level

A Microorganism's level is also based upon your current Protein setup.

For example, if you have a setup of [2, 2, 2, 2, 2, 2, 2, 2], the game would register it as a Level 2 Amoeba, as it has a minimum of [1, 1, 1, 1, 1, 1, 1, 1] proteins, and each protein is 2× the base requirement.

For another example, let's make a Level 4 Yeast.

The Protein setup to generate this would be [0, 12, 0, 0, 0, 12, 12, 4], because each protein has 4× the amount of [0, 3, 0, 0, 0, 3, 3, 1], the base Protein setup requirement for Yeast.

In conclusion, for a Microorganism to be level n, your Proteins must have n× the amount of the base requirement of the type.

Starting at level 20, your level gain is softcapped due to overpopulation.
